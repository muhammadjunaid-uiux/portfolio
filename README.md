# Muhammad Junaid Ashraf — UI/UX Designer Portfolio (Premium Dark v2)

A clean, GitHub-ready, zero-build static portfolio website created from
Muhammad Junaid Ashraf's CV.

## What is included

- Premium Black/Dark futuristic UI/UX portfolio
- Responsive desktop / tablet / mobile design
- Real CV content
- Real project links from the CV
- Real LinkedIn and portfolio archive links
- Extracted profile photo from the CV
- Downloadable original CV
- Project category filters
- Smooth reveal animations
- Reduced-motion support
- GitHub Pages compatibility
- Cloudflare Pages compatibility

## Run locally

No npm or build step is required.

Simply open:

`index.html`

You can also run any static server, for example:

```bash
python -m http.server 8080
```

Then open:

`http://localhost:8080`

## GitHub Pages

1. Create a GitHub repository.
2. Upload every file/folder from this project to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.

## Cloudflare Pages

- Framework preset: **None**
- Build command: leave empty
- Output directory: `/`

## Update the site

### Main content
Edit `index.html`.

### Design / colors / spacing / animations
Edit `assets/styles.css`.

### JavaScript interactions
Edit `assets/app.js`.

### Profile image
Replace `assets/junaid-profile.png`.

### CV
Replace `assets/Muhammad_Junaid_Ashraf_CV.pdf` while keeping the same filename,
or update the links in `index.html`.

## Important

Project descriptions, experience, contact details, education and portfolio
